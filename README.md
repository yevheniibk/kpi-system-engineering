## 📌 Про проект

Цей репозиторій містить повний комплекс матеріалів індивідуального проекту: як графічні SysML-моделі системи «Пивоварня» (діаграми Структурна, Use Cases, Activity, Requirements, State machine, Sequences), так і її програмну реалізацію мовою Python. Мета проекту — побудова об’єктно-орієнтованої моделі системи на основі специфікації на мові SysML.

## 📂 Структура репозиторію

Проект складається з трьох основних файлів:

* 📄 **`main.py`** — код об'єктно-орієнтованої моделі пивоварні.
* 📄 **`Brewery_Documentation.docx`** — пояснювальна записка до коду.
* 📄 **`Brewery_Diagrams.docx`** — файл із побудованими SysML діаграмами, які лягли в основу програмної архітектури.

## 🏗️ Структура підсистем (програмна реалізація)

Код у `main.py` моделює 11 ключових вузлів пивоварні, які взаємодіють між собою:

1.  **MillingSystem** — помел солоду.
2.  **MashingSystem** — затирання.
3.  **WortFiltrationSystem** — фільтрація сусла.
4.  **BoilingSystem** — кип'ятіння з хмелем.
5.  **ThermalProcessingSystem** — охолодження.
6.  **FermentationSystem** — бродіння та дозрівання.
7.  **FinalFiltrationSystem** — фінішна фільтрація та освітлення.
8.  **BottlingPackagingSystem** — розлив та пакування.
9.  **SanitationSystem** — санітарна обробка (CIP-мийка).
10. **PowerSupplySystem** — енергозабезпечення.
11. **ControlAutomationSystem** — автоматизація та логіка рецептів.
